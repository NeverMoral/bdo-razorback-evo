# Сайт BDO Guide EVO

Эта папка — готовый сайт для публикации на GitHub Pages. Загружайте **всё содержимое папки** в корень репозитория, сохраняя структуру каталогов.

## Структура

- `index.html` — гайд и переключатель «Гайд / Трекер».
- `assets/` — изображения и прочие файлы гайда.
- `tracker.html` — общая оболочка сайта с переключателем разделов.
- `tracker/index.html` — оригинальное приложение трекера без изменений.
- `tracker/bdo_ship_assets/` — оригинальные ресурсы трекера без изменений.

## Как обновлять независимо

### Гайд

Редактируйте только корневой `index.html` и папку `assets/`. Не удаляйте блок `app-switcher` в шапке — он связывает гайд с трекером.

### Трекер

Обновляйте только содержимое папки `tracker/`: замените в ней `index.html` и `bdo_ship_assets/` свежей версией из рабочего проекта трекера. Файл `tracker.html` менять не нужно — это только общая шапка сайта. Благодаря этому исходный трекер остаётся самостоятельным приложением и не смешивается с кодом гайда.

## Автоматическое сохранение

Гайд и трекер сохраняют прогресс автоматически в `localStorage` браузера. Их данные используют разные ключи и не перезаписывают друг друга. Переход между разделами или обновление страницы не сбрасывает прогресс.

Важно: данные хранятся в конкретном браузере и на конкретном адресе сайта. Очистка данных браузера, приватный режим или переход на другой домен могут скрыть локальный прогресс. Для важных данных используйте встроенный экспорт/резервную копию трекера.

## Публикация на GitHub Pages

1. Загрузите всё содержимое этой папки в корень репозитория.
2. Откройте `Settings → Pages`.
3. Выберите `Deploy from a branch`, ветку `main` и каталог `/ (root)`.
4. После публикации откройте адрес Pages и проверьте обе кнопки в верхней части сайта.

Главная страница сайта — `index.html`.
